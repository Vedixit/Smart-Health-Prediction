Welcome to Smart Health Prediction System

The Smart Health Prediction System is an AI-powered web application designed to assist users in identifying potential diseases based on the symptoms they experience. By leveraging the power of machine learning, the system provides quick, accessible, and reliable predictions, helping users take early action for their health and well-being.

This platform is especially helpful for people who may not have immediate access to healthcare professionals. Users can simply register or log in, input their symptoms in a user-friendly form, and receive a prediction generated by a trained machine learning model.

The system also stores user history securely, enabling them to monitor past predictions. Additionally, administrators can monitor platform usage and manage user data through a dedicated Admin Panel.

Whether you're a student building an innovative health tech solution or someone looking for a quick health check, this system is built to be efficient, responsive, and easy to use.

Admin Panel

The admin panel gives authorized administrators access to all system records. It includes a dashboard to monitor registered users, their prediction activity, and system usage statistics.

Each row in the admin table includes the user's name, email, symptoms entered, predicted disease, and date of prediction. This helps in auditing system usage, understanding common symptoms, and managing backend records effectively.

The admin interface ensures data transparency and allows for future enhancements like analytics and user trend analysis.
